## About this repository

This repository contains the supplementary tables and figures accompanying the doctoral thesis *Genomic Evolution of Livestock Associated Staphylococcus aureus: Host Adaptation and Rabbit Lineage Emergence*.

The thesis investigates the population structure, comparative genomics, pangenome evolution, antimicrobial resistance, virulence-associated repertoires, and mobile genetic elements of livestock-associated *Staphylococcus aureus*, with a particular focus on rabbit-associated lineages and prophage-related phenotypes.

The work comprises three research chapters:

- **Chapter 1 — Comparative Genomics of *Staphylococcus aureus* across Six Livestock Hosts: Population Structure, Pangenome, Resistome, and Mobilome.** Comparative analysis of 1,884 isolates from pigs, cattle, rabbits, poultry, goats, and sheep.
- **Chapter 2 — Comparative Genomics, Phylogenomics and Virulence of Rabbit-Associated *Staphylococcus aureus*.** Analysis of 358 rabbit-associated isolates, including population structure, evolutionary and accessory-genome patterns, and virulence-related experiments.
- **Chapter 3 — Evolutionary History and Prophage Co-carriage in the Recent Diversification of Rabbit-Associated *Staphylococcus aureus* ST3764.** Phylogenomic and temporal analyses of 196 CC121 genomes (134 ST121 and 62 ST3764), prophage characterization, and bacteriophage susceptibility experiments.

## Data interpretation and availability

The tables are provided as Excel (`.xlsx`) files and the figures as PNG (`.png`) images. They supplement, but do not replace, the methods, figure legends, results, and limitations described in the thesis.

Genome-associated identifiers and metadata should be interpreted using the definitions provided in the relevant tables and thesis chapters. Predicted mobile genetic elements, mobility classes, and phage-associated functions are computational assignments unless explicitly supported by experimental validation.

For a fixed, citable snapshot of these materials, use a tagged GitHub release once the repository is finalized. The release version should be recorded alongside the repository URL in the thesis.
